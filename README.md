# Personal Assistant (PA) Finance App

## GitHub Actions ဖြင့် APK ထုတ်နည်း
1. ဤဖိုင်များအားလုံးကို GitHub Repository အသစ်ထဲသို့ Upload တင်ပါ။ (`.github` ဖိုဒါပါ ပါဝင်ကြောင်း သေချာစစ်ပါ။)
2. Repository အပေါ်ဘားရှိ **Actions** tab ကို နှိပ်ပါ။
3. **Build Android APK** အလုပ်လုပ်ပြီး အစိမ်းရောင် အမှန်ခြစ် (✅) ပြသွားပါက နှိပ်ဝင်ပြီး အောက်ဆုံးရှိ **Artifacts > Personal-Assistant-APK** ကို Download ဆွဲ၍ Install လုပ်နိုင်ပါသည်။
